# **App Name**: Squara: CryptoTracker

## Core Features:

- Real-time Data Fetching: Fetch real-time price data for Bitcoin, Solana, and Ethereum from cryptocurrency APIs.
- Currency Conversion: Convert cryptocurrency prices to both BRL (Real) and USD (Dollar).
- Interactive Charts: Display cryptocurrency prices using interactive charts that are filterable by time range.
- Time Range Selection: Allow users to select time ranges for the chart, including options for 'now', '24 hours', '1 week', '1 month', and '1 year'.
- User-Friendly Interface: Provide a clean, intuitive, and easy-to-navigate user interface.

## Style Guidelines:

- Primary color: Use a vibrant blue (#29ABE2) to represent trust and financial technology.
- Background color: Light gray (#F5F5F5), creating a clean and modern feel.
- Accent color: Green (#2ECC71) for positive trends and key actions, such as "update prices".
- Font pairing: 'Inter' sans-serif for both headlines and body text to ensure readability and a modern aesthetic.
- Use simple, outline-style icons to represent different cryptocurrencies and chart options, providing a minimalist and intuitive user experience.
- Use a clean, card-based layout to present cryptocurrency data and charts in an organized manner. Prioritize key information such as current prices and percentage changes.
- Incorporate subtle transitions when updating data or switching between time ranges. A loading animation should be included when fetching the information
